# 内部接口约定

research/models.py: fit_predict_models(X_train,y_train,X_val,y_val,X_test, *, seed=42, config=None, train_dates=None) returns (predictions, metadata). predictions keys: ridge, mlp, mlp_resample, mlp_diffusion, values numpy arrays aligned to X_test. metadata maps model names to JSON-serializable training/config info; errors must be reported, no silent substitutes. X are finite numeric feature matrices; y decimal future excess returns. Generator/preprocessor fit train only.

research/portfolio.py exports PortfolioConfig dataclass, target_weights(scores, history_returns, config), make_order_drafts(weights, prices, capital, current_quantities=None, as_of=None, run_id=None, config=None), backtest(prices, predictions, benchmark, config). Scores pd.Series symbol->score. history_returns pd.DataFrame indexed dates, columns symbols. target_weights returns (dict weights, dict diagnostics). OHLC prices DataFrame date,symbol,open,close; predictions date,symbol,score. benchmark DataFrame date,open,close. backtest returns JSON-serializable dict with series (date,equity,drawdown,benchmark_equity,cash_weight,turnover), trades, metrics. Backtest exact next-open execution, configured horizon trading-day rebalance, transaction costs and evolving holdings. No live brokerage access.

runs/latest.json: {status,run_id,created_at,data:{source,symbols,start,end,n_dates,quality,errors},config,experiments:[{model,metrics,training}],series:{ic:[{date,model,value}],equity:[{date,model,equity,drawdown,benchmark_equity,cash_weight,turnover}]},predictions:[{date,symbol,model,score,realized_excess}],decision:{model,as_of,weights,diagnostics,orders,capital,reference_prices},lineage,warnings}. status is completed/data_unavailable/insufficient_data/failed; absent results display missing, never mock returns.

Root orchestration provides collection and dataset. Models and portfolio modules must not write runs/latest.json. UI reads it, does not submit orders. Shared config contains portfolio nested dictionary and model settings. Streamlit installed version1.37.1; use compatible API. Plotly5.24.1. All timestamps UTC ISO plus market session date.
