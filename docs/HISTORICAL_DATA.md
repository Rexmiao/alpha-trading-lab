# 使用真实历史行情

公网应用的 `Upload CSV / 上传 CSV` 使用文件里的日K训练和回测。CSV是默认来源，访客也可使用；Synthetic teaching data需明确选择，且始终标记为教学样本。格式错误或样本不足会报错，不会自动换成合成数据。

本机已从现有moomoo日K快照整理8只研究股票及SPY：NVDA、AMD、AVGO、MU、WDC、SNDK、NBIS、CRWV。它们是本次主题研究范围，不是已确认的用户持仓。

窗口为2025-04-24至2026-11-24，400个基准交易日，每个代码400条，共3600行。源数据采集于2026-11-25T09:04:55.350Z；当时美东11/25尚未收盘，因此没有把当日进行中的K线当作完整历史。不补缺口、不生成上市前价格，并应用SNDK、CRWV与NBIS的配置起点。

固定CSV的SHA256为`8748612159d562adc85661068f149d9f8ce9ea82bdcaa75b56276860a45acc17`。CSV和包含来源路径、原始响应哈希、覆盖范围及质量核查的sidecar保存在本机`data/cloud-inputs/`，不纳入GitHub或Space源码。结果保存在本机会话报告目录，不作为公开市场业绩展示。

## 在网页里运行

1. 打开任一已部署应用，在左侧选择 **Upload CSV / 上传 CSV**。
2. 上传本机准备好的七列CSV，基准填 **SPY**。
3. 周期默认5个交易日，可输入1–20的整数；初期建议在10个交易日以内研究，这是教学起点，不是最优参数。
4. 点击Run后才训练；核对数据来源、日期、模型状态、Rank IC、含成本净值和回撤，再下载JSON保存。

CSV只允许以下列，同一文件须含基准和3–12只股票：

```text
date,symbol,open,high,low,close,volume
```

当前上限3MiB、8000行、600个日期、3000训练样本。此8股400日快照在默认5日期下有2144训练样本，满足预算。模型仅使用训练期，按实际label_end剔除跨边界标签；持有期和调仓间隔使用同一个周期。

## 来源与质量

上传文件会发送到所选云端应用临时处理，结果只在当前会话中保留；页面不会访问访客电脑的moomoo本机接口。模型从CSV读取数据，不持有券商凭据，也不提交订单。公开源码、默认教学样本与个人上传文件分别处理；本次真实CSV没有写入公开仓库。

moomoo快照为前复权OHLC，仍是可成交价近似；固定现时股票池存在选择及生存者偏差。审计发现三次超过30%的收盘变化，已用Yahoo日线在六个收盘样本点交叉核对，至美分一致，保留原值；这不是对400日数据和公司行动的完整独立审计。来源和抽查记录保存在本机sidecar。

严格复现请保留同一CSV、SHA256、源码版本、依赖与JSON配置。重新下载或重新采集可能改变历史复权值。上传CSV这一来源标识本身不证明文件是市场真值；应同时保留自己的数据来源与质量记录。

## 在线获取与访客入口

不需要登录或券商密钥。访客可上传自己的合规OHLCV CSV，也可选择 **Online history / 在线历史行情**，填写3–8只USD股票或ETF及基准。在线默认7股为NVDA、AMD、AVGO、MU、WDC、NBIS、CRWV，另加SPY、最近400个基准日期；保守排除美东当前日期。仅点击Run后获取并训练，不保证数据商始终可用或不限流。

在线源为Yahoo公开日线，OHLC采用adjclose/close比率同步缩放，成交量保留来源值；与moomoo快照口径分别标记。上市前及缺失数据不会补填，币种、时区、HTTP错误、空数据与非法价格均明确报错，不会回退为合成样本。

在线快照仅在本会话缓存，同一数据下更改模型周期/成本/仓位时复用；主动刷新或变更股票/基准才重新获取。可下载行情CSV快照及来源JSON，保留来源参数、各响应SHA、覆盖和获取时点。当前可下载快照和正在显示的旧运行结果若不同，会分别注明，避免把新数据误标成旧结果的输入。

本次在线源校验发现SNDK有部分字段缺失，未将其自动补齐或放弃后继续；在线默认名单因此显式不含SNDK，用户输入它时仍按相同质量规则校验。moomoo固定CSV含SNDK完整窗口，两种来源的股票范围分别记录。
